# ROI previews

Lightweight contact sheets for the `Casting_class1` functional-surface ROI
segmenter.

These images are copied from the generated ROI prediction folders so that the
GitHub report can show the ROI behavior without versioning the heavy prediction
artifacts (`functional_surface_predictions.npz`, probability maps, masks).

Files:

- `roi_good_*.png`: ROI previews on good test images.
- `roi_defective_*.png`: ROI previews on defective test images.
- `roi_full_*.png`: combined good + defective ROI previews.
